# Ayak Parmakları İçin Anayasa

Bu belge, insanlık tarihinin en az okunan ama en çok ihlal edilen metnidir.

## Amaç

On adet parmağın haklarını, ödevlerini ve Lego ile olan tarihsel düşmanlığını yazıya dökmek.
Proje bilimsel değildir. Hukuki de değildir. Yine de kendinden emindir.

## Kurulum

```bash
python3 anayasa.py
```

Başka bir şey kurmayın. Kurarsanız parmaklar toplanır.

## Kullanım

Çalıştırın. Meclis kendiliğinden toplanır. Karar çıkar. Kimse uygulamaz.

## Katkıda Bulunma

Pull request atabilirsiniz. Serçe parmak onaylamazsa birleştirilmez.
